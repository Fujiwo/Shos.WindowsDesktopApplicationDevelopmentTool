## 書き方

出来事が起きたその場で、1 件を表の 1 行として追記する。後から思い出して書かない。

### 書くきっかけ

| きっかけ | 書くこと |
|----------|----------|
| スキルを呼んだとき、reference を読んだとき | 作業の種類、読んだ reference と節。その作業の「必ず読む」を読まなかったときは、そのこと |
| スキルで判断が変わったとき | 何がどう変わったか。スキルのどの規則・節か |
| スキルに従った判断を採らなかったとき | 採らなかった理由（CLAUDE.md、ユーザーの指示、既存の流儀など） |
| 七箇条に当てはまらない指摘が出たとき | その指摘と、「整合」「正しさ」のどちらで拾ったか |
| 臭いの表にない症状の名前で指摘したとき | その名前（表に足す候補になるかの材料） |
| 実行環境（Windows 側）で不具合が見つかったとき | どの作業のどの観点なら拾えたか。スキルの範囲の内か外か |
| ユーザーが Claude の判断を直したとき | 直された判断がスキル由来だったか。どの規則か |
| スキルと CLAUDE.md・ユーザーの指示がぶつかったとき | どちらに従い、なぜか |
| スキルの文言で迷ったとき | 迷った箇所と、どう解釈したか（改善案の材料） |
| 成果物を承認されたとき | その成果物でのスキルの使われ方の要約を 1〜3 行 |
| 基準の評価で入れた改良の文（S 番号）が判断に効いたとき、効くはずの場面で効かなかったとき | 案の番号と、その場面 |
| 会話が圧縮された後に、スキルの規則を使ったとき | SKILL.md のその節の本文が手元にあったか（なければ読み直したか） |
| reference を読んだのに、判断に引かなかったとき | 読んだ reference と節（読まれるだけの節を見つけるため） |

### 判定の区分

| 区分 | 意味 |
|------|------|
| スキル | スキルがあったから起きた。スキルの規則・節を具体的に指せる |
| スキルなし | スキルがなくても起きたと思われる。CLAUDE.md やユーザーの指示、ほかの手順が直接の理由である |
| 判別できない | どちらとも言えない |
| — | 判定の対象でない（読んだことの記録、条件の変更など） |

- スキルの語で言い換えただけのものは「スキル」にしない。
- 「スキルなし」「判別できない」も、効かなかったことの記録として同じ重みで書く。
- 根拠は、本文を写さず、場所（ファイルと節、指摘の番号など）を指す。

### 一巡の最後に数えるもの

基準と同じ物差しで比べる。

- レビューの指摘の数を、観点（七箇条の各箇条、引き算、整合、正しさ）ごとに
- 指摘とリファクタリングの対象のうち、臭いの表の名前を使った割合
- 「必ず読む」を守った割合（作業の種類ごと）
- 実行環境（Windows 側）で見つかった不具合の数と、拾えたはずの作業・観点
- ユーザーに直された判断の数と、そのうちスキル由来のもの
- 判定の区分ごとの件数
- reference と節ごとの、読んだ回数と判断に引いた回数
- 改良の文（S 番号）ごとの、効いた回数と効かなかった回数

一巡の間に、スキルの使い方の条件（CLAUDE.md の「コーディング規範」、スキルのファイル、設定）を変えたら書く。前後で比べるときの区切りになる。

| 日付 | 変更 | 理由 |
|------|------|------|
| 2026-10-14 | CLAUDE.md の「コーディング規範」を、Shos.Minesweeper から写した版からこのプロジェクト向けに書き直した（工程の表と、無いファイル・記号への参照を外し、レビューの観点と実行環境での確認を WSL と Windows の差に合わせた）。xUnit の導入を合意済みとし、「スキルの評価の記録」の節とこのファイルを足した | ユーザーの指示（一巡を始める前の条件） |
| 2026-10-14 | 基準の評価を Shos.Minesweeper から docs/for-skills/reviews/skill-evaluation-minesweeper.md に写し、CLAUDE.md とこのファイルの参照をそちらに改めた。中身は元と同じ | ユーザーの指示。元のファイルは変えない |
| 2026-10-14 | 基準のファイルの名前が skill-evaluation-basement.md に変わっていたので、このファイルの「基準」の参照を改めた（上の行は当時の記録として残す）。CLAUDE.md の参照はすでに basement を指していた。中身は変えていない | リポジトリのレビューの指摘 1（参照の食い違い） |
